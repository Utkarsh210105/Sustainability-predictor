🌱 Sustainability Checker

A simple Streamlit web application that predicts whether a system/product is sustainable based on four input parameters.
The prediction is made using a trained Logistic Regression model (lrmodel_sustainable.pkl).
🚀 Features

User-friendly Streamlit interface
Takes 4 inputs:

Carbon Emission
Energy Output
Renewability Index
Cost Efficiency

Uses a machine learning model to classify:

✅ Sustainable
❌ Not Sustainable
